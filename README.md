# CONecta V2

Rede escolar demonstrativa com front-end estático e estrutura de back-end Firebase.

1. Leia [`DEPLOY.md`](DEPLOY.md) para configurar o Firebase e publicar pelo GitHub Actions.
2. Preencha a configuração pública do app Web Firebase em `services/firebase-config.js` quando o projeto Firebase estiver pronto.
3. Envie o conteúdo desta pasta ao repositório GitHub. Com os secrets de deploy definidos, cada commit em `main` executa verificações, build e publicação.

Sem configuração Firebase, a interface abre em **Demonstração local**. O serviço de Libras também fica desativado até a escolha e configuração do provedor.
